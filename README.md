# Akham Films — Site officiel

> "Nous ne faisons pas des films. Nous allumons des lumières."

Site web officiel d'**Akham Films**, société de production cinématographique algérienne fondée en 2019.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS v3
- Framer Motion v11
- React Hook Form + Zod
- Resend (envoi d'emails)
- Lucide React

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Variables d'environnement

Créer un fichier `.env.local` :

```
RESEND_API_KEY=...
CONTACT_TO_EMAIL=hello@akhamfilms.dz
```

## Concept

Le site se comporte comme une salle de cinéma numérique. Le visiteur n'arrive pas
sur un site web — il entre dans une expérience.

Voir le brief créatif complet pour la direction artistique détaillée.
